# Knowledge v12 → v13 검수 기반 상호작용 쌍 A/B

## 목적

일반 연구 문서의 성분 동시 등장으로 생성된 `interaction_pair_keys`를 제거하고,
문서별 검수 주석과 근거 문구가 일치하는 직접 관계만 exact pair 검색에 남겼을 때
미량영양소 상호작용 검색의 출처 정확도가 개선되는지 확인한다.

## 고정 계약

- 평가 파일: `micronutrient_interactions_v12_queries.yaml`
- 평가 질문: 철분–아연, 아연–구리, 비타민 C–철분 3개
- 비교 대상: `medication_knowledge_full_v12` / `medication_knowledge_full_v13`
- 임베딩: `text-embedding-3-small`, DOT
- 판정 원칙: 정확도 우선. Hit@5, MRR, 인용 정확도, 잘못된 대상 혼입을 먼저 보고
  지연 시간은 경고 지표로 함께 기록한다.

## 릴리스 구성

- v13 청크: 8,642개, 문서 1,212개
- v12 벡터 재사용: 8,642개
- 문서 본문 재임베딩: 0개
- `DEMO_RESTRICTED` 청크의 신규 외부 전송: 0개
- exact pair 청크: v12 45개 → v13 23개
- exact pair 문서: v12 12개 → v13 7개
- v13의 7개 pair 문서는 검수 주석 manifest의 7개 문서와 정확히 일치한다.

## 활성화 판정

`ACTIVATE`

v13은 정확도 계약을 충족했다. 특히 잘못된 일반 문단을 철분–아연의 직접 관계
근거로 취급하던 원인이 제거되어, 인용 정확도와 MRR이 모두 1.0이 되었다.

검색 P95는 300ms 기준을 6.931ms 초과해 지연 시간 경고가 남는다. 다만 본 평가의
우선순위는 정확도이며, 비교기는 정확도 개선과 안전성 유지에 따라 활성화를 권고했다.
향후 더 큰 평가 세트에서 P95를 다시 측정한다.

## 구현 근거

1. `KnowledgeEntityExtractor`는 검수 주석이 없는 연구 문서에서 pair key를 자동 생성하지 않는다.
2. 릴리스 재조합은 기존 연구 문서에 남아 있던 추정 pair key를 제거한다.
3. 검수 주석의 대상·근거 문구가 해당 청크에 함께 있을 때만 pair key를 다시 부여한다.
