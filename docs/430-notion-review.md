# #430 Notion 요구사항 검수

기준: 2026-09-12 확정 사용자 결정이 이전 Notion 제안보다 우선한다. 이후 사용자가 `복약 체크 표시 기능이 애매함`, `OCR 약정보 UI` 두 항목을 취소했다. 일부 복용 선택은 기존 동작을 유지한다. 최신 추가 요청에 따라 처방 목록의 복용 시간은 고정된 네 열의 표로 표시하고, 홈은 처방별 전체 테두리로 구분한다.

## 링크별 처리 결과

1. [복약 체크 표시 기능이 애매함](https://app.notion.com/p/3d97226115e78021ad04e4f4307f10b5) — **cancelled**
   - 해당 항목 취소에 따라 미완료 복약 버튼 문구를 기준 동작인 `먹었어요`로 복원했다.
   - 기존 일부 복용 선택, 선택/전체 대상 기록, 완료 상태의 `복약 기록 되돌리기` 동작은 유지했다.
2. [홈 오늘의 복약/영양제 빈 상태 UI 통일](https://app.notion.com/p/3d97226115e780a1bf0af0b0ac1e702a) — **fixed**
   - 두 빈 상태를 같은 카드 배경·간격·패딩 구조로 맞췄다.
   - 영양제 빈 상태에 `영양제 살펴보기` 버튼과 탐색 연결을 추가했다.
3. [홈 오늘의 복약 펼치기](https://app.notion.com/p/3d97226115e780099e7ce233f83c1523) — **fixed**
   - 펼친 처방의 상세 약명을 보통 굵기로 변경했다.
4. [약봉투 미리보기](https://app.notion.com/p/3d97226115e78025b6a3f20ac3411f9a) — **fixed**
   - 화면에 맞춘 100% 이미지 크기를 기준으로 정확한 150/200/300% 확대·축소와 이동 가능한 스크롤 영역을 제공한다.
   - 375/390/1280px에서 확대 전후 실제 이미지 크기와 스크롤 시작/끝 좌표를 측정해 네 모서리 도달성을 검증했다.
   - 확대·축소 버튼, 보기 전환, 닫기 버튼은 모두 44px 이상이며 키보드 확대, Escape와 명시적 닫기를 검증했다. 비의미적 이미지 클릭 닫기는 제거했다.
   - 터치 영역은 브라우저의 `pinch-zoom`을 허용하지만 실제 물리 pinch 제스처는 자동화 검증 범위에 포함하지 않았다.
5. [복약 상단 버튼 영역](https://app.notion.com/p/3d97226115e78040862fd97600c127a8) — **fixed**
   - `AI 보고서 받기`는 주 동작, `처방 추가`는 보조 동작으로 시각적으로 구분했다.
   - 목록을 불러온 뒤 `복용 중 N개`는 왼쪽, `처방 추가`와 `선택`/`삭제`는 오른쪽의 같은 행에 둔다.
   - 유휴 `선택`, 선택 중 `삭제`, 헤더 `취소` 경로를 제공하고 삭제 버튼은 항목 선택 전 비활성화했다.
   - 로딩·오류·빈 상태의 독립 액션과 완료 목록 섹션은 기존 구조를 유지한다.
   - 상단 `복약 메모` 버튼의 카드 그림자를 보존했다.
6. [복약 아침/점심/저녁 색상](https://app.notion.com/p/3d97226115e780588f8feab165166ef6) — **fixed / superseded**
   - 50:50 중간톤 시간대 점과 `복용 중` 스티커를 유지했다.
   - 최신 추가 요청에 따라 연필은 상태·남은 일수 줄, 펼침 화살표는 병원명 줄에 정렬한다. 독립 버튼과 44px 이상 터치 영역을 유지한다.
   - 상단 시간대 범례를 제거하고 펼친 처방은 `복용약 | 아침 | 점심 | 저녁 | 자기전`의 고정 열로 표시한다. 미복용 시간 열은 빈칸을 유지하고 활성 시간은 중간톤 점으로 표시한다.
   - 필요 시 복용 안내와 끝까지 복용 표시는 유지하며 복용량·HH:mm을 중복 표시하지 않는다. 기존 비-feature252 카드의 개별 시간 편집은 유지한다.
7. [OCR 약정보 UI](https://app.notion.com/p/3d97226115e780a4a4c4c00de107da5f) — **cancelled**
   - 함량/횟수 줄바꿈과 접기·펼치기 제안은 취소되었다. 이번 #430 제품 diff에는 이 항목의 신규 변경이 없어 되돌릴 코드가 없다.
   - 기존 승인 상태인 항상 펼침·연필만·약명 옆 `확인 필요` 표시는 유지한다. 별도 4번 `약봉투 미리보기` 확대·축소도 취소 대상이 아니다.

## 추가 사용자 작업

- **fixed — 오늘의 복약 처방별 구분**
  - 각 처방의 제목과 펼친 약 목록 전체를 하나의 얇은 테두리로 감싸고 처방 사이 간격을 둔다.
  - 헤더/상세의 부분 하단 선을 제거하고 기존 선택·펼침·일부/전체 복용·되돌리기·완료 태그 위치는 유지한다.

- **fixed — 영양제가 등록되어 있으면 홈 `영양제 살펴보기` 제거**
  - 등록된 영양제 카드 아래의 별도 탐색 버튼을 제거했다.
  - 빈 상태 안내와 탐색 버튼은 등록 목록이 실제로 비었을 때만 제공하며 `/supplements?tab=browse` 이동을 유지한다.
  - 등록 항목의 복용 전·전체 완료·미래 시작(오늘 회차 없음)·로딩·조회 오류에서 버튼이 나타나지 않도록 검증했다.
  - 복용 선택·저장·되돌리기와 날짜·API 로직은 변경하지 않았다.

- **fixed — 오늘의 복약 `복용 완료` 태그 위치 통일**
  - 별도 Notion 링크가 제공되지 않은 추가 요청으로, 링크를 추정하지 않았다.
  - 시간대 제목 옆 전체 완료 태그를 제거하고 완료된 각 처방의 처방명 위에 동일한 태그를 유지한다.
  - 일부 완료·전체 완료·숨겨진 세 번째 처방·특정 처방 되돌리기·저장 실패 롤백에서 같은 규칙을 검증했다.
  - 복약 선택/기록 의미와 복원된 `먹었어요`/`복약 기록 되돌리기` 문구는 변경하지 않았다.
