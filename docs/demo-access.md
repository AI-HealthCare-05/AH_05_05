# 데모 접속 설정

서버 환경변수에 아래 값을 설정하고 FastAPI를 재시작한다.

```dotenv
DEMO_LOGIN_ENABLED=true
DEMO_LOGIN_EMAIL=demo_tester@rxvita.p-e.kr
DEMO_LOGIN_PASSWORD=<데모 계정의 실제 비밀번호>
```

비밀번호는 서버 `.env` 또는 GitHub Environment의 `PROD_ENV_FILE` Secret에만 넣는다.
프론트 VITE 환경변수, Git 추적 파일에는 비밀번호를 넣지 않는다.
해당 계정은 미리 가입되어 ACTIVE 상태여야 하며, 환경변수 설정이 회원을 자동 생성하거나 비밀번호를 변경하지는 않는다.
첨부파일 암호화에 필요한 생년월일을 계정에 설정해야 한다. 수신자는 해당 생년월일 6자리(YYMMDD)로 첨부파일을 연다.
데모 계정에는 실제 개인정보나 개인 의료정보를 넣지 않는다. 방문자는 같은 계정의 데이터를 공유한다.

- `/demo`: 서버 설정으로 인증 후 `/home`으로 이동. 브라우저에 비밀번호를 전송하지 않는다.
- `/home`: 데모 진입 세션에서만 빨간색 `[데모 버전]` 표시. 새로고침 유지, 로그아웃/만료/일반 로그인 시 해제.
- `/my/profile`: 데모 계정은 비밀번호 변경·탈퇴 버튼에서 안내만 표시한다. API에서도 차단한다.
- 공유 계정 보호를 위해 이메일 변경과 비밀번호 찾기에 의한 재설정도 차단한다.
- `/reports/new?source=supplements`: 데모 세션은 이메일 수신 주소 입력 후 확인해야 발송한다.
- 서버는 데모 계정에만 수신 주소 변경을 허용한다. 일반 계정은 기존 인증 이메일로 발송한다.
- 보고서 스냅샷 검증 및 기존 보고서 단위 중복 방지, 암호화 첨부파일을 유지한다.
- 데모 계정 전체의 시간당 발송 횟수 제한은 적용하지 않는다. 동일 보고서의 중복 발송 방지는 유지한다.
- 실제 AWS 설정 변경, 계정 생성, 운영 메일 발송은 코드 반영과 별도 작업이다.
