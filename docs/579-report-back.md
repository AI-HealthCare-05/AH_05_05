# #579 AI 보고서 복귀 경로

- 기준: origin/main `6f0f5fd`, 독립 브랜치 `feature/579`.
- 재현: 홈 → 복약/영양제 → 보고서 → 상단 뒤로가기 → 원래 탭 → 뒤로가기 시 보고서가 다시 열림. 양쪽 탭의 회귀 테스트가 수정 전 실패했다.
- 원인: 보고서의 복귀 버튼이 `navigate('/원래탭')`으로 방문 이력을 추가했다.
- 변경: 진입 탭을 라우터 state에 남기고, 확인된 진입 경로가 있으면 기존 이력으로 복귀한다. 직접 URL 진입은 원래 탭으로 replace한다. 복약 탭도 이력이 없으면 홈으로 replace한다.
- 범위: 보고서 상단·하단 및 빈 결과의 관리 이동 버튼. 보고서 생성 API와 분석 정책은 변경하지 않는다.
- 검증: 복약/영양제 각각 상단·하단·브라우저 뒤로가기·새로고침·직접 진입을 Chromium/WebKit에서 확인한다. 합성 데이터의 로컬 자동 테스트이며 실제 iPhone/배포 확인과 구분한다.
- 독립 코드 검토: 실제 결함 지적 없음. 검토자는 브라우저 테스트를 재실행하지 않았다.
- 결과: `tsc --noEmit` 통과, Chromium/WebKit 20/20 통과(1.9분). 보고서를 생성하지 않고 모든 복귀 경로를 검증했다. 테스트 종료 무렵 일부 취소 요청이 로컬 8000 프록시에 도달해 서버 로그에 연결 거절이 남았으나, 시나리오 검증은 모두 통과했다. 배포 및 실제 기기 검증은 수행하지 않았다.
