# Directional Query 고정 평가 세트 v1

## 목적

규칙 기반 Query Plan이 후보와 요청 섹션을 만든 뒤, 저신뢰도·복수 대상·세션 참조일 때만 실행되는 Directional Query 체인의 품질을 반복 측정한다.

## 평가 계약

- 입력 후보 밖의 제품·성분·pair key를 선택하지 않는다.
- 질문의 요청 섹션을 보존한다. `효능과 주의사항`은 `FUNCTION`, `CAUTION`을 함께 유지하며 관계 표현이 없으면 `INTERACTION`을 추가하지 않는다.
- 상호작용 질문은 입력에 있는 pair key만 선택한다.
- 모호한 범위 질문은 검색 자극 대신 확인 질문을 선택할 수 있다.
- 검색 자극은 허용 검색어와 선택된 후보를 조합한 경우만 인정한다.

## 측정 항목

- 후보 보존율: 필수 후보 키가 출력에 남아 있는 비율
- 섹션 보존율: 필수 section이 출력에 남아 있는 비율
- 허용 범위 위반율: 후보·pair key·검색어를 새로 만든 비율
- 확인 질문 적합도: 모호한 질문에서만 `needs_clarification=true`인지
- 지연시간: 구조화 입력부터 출력 검증까지의 wall-clock 시간

## 채택 기준

- 후보·pair key 범위 위반 0건
- 필수 section 보존율 100%
- 모호 범위 질문 확인 질문 적합도 100%
- 규칙 기준선보다 검색에 필요한 정보가 늘어나되, P95 지연시간은 별도 기록해 판단
