# #369 UI 검수 피드백 반영

기준 커밋: `a459540`. 작업 및 검수 브랜치: `feature/369`.

## 반영 범위

1. 큰 회색 로딩 상자를 의미 있는 지연 상태 안내로 교체했다. 빠른 응답에는 안내가 깜빡이지 않으며, 콘텐츠 최초 등장은 짧은 fade를 사용한다. 홈 복약 영역 높이는 측정 기반 240ms 전환으로 바뀐다. 홈 챌린지는 같은 계정 재조회 중 기존 카드를 유지하고 최초 로딩에 기본 카드 높이를 확보한다. 모든 레이아웃 이동 자체를 없앤다는 의미는 아니다.
2. 하단바가 있는 기존 페이지의 높이를 viewport에 제한하고 내용 영역만 스크롤한다. 긴 복약·마이·프로필 및 상세 화면에서도 하단바를 유지한다.
3. 펼친 복약 카드의 시간대 칩에서 HH:mm만 제거했다. 아침/점심/저녁/자기전 구분과 실제 복용 스케줄·수정 저장값은 유지한다.
4. 챌린지 둘러보기 카드를 이름과 모집기간으로 압축하고 상세 이동 화살표를 제공한다. 진행 중 공식 항목과 모든 대상이 참여 중인 복약 맞춤 항목은 회색·비활성·하단 정렬한다. 과거 참여 이력만 있는 공식 항목은 현재 참여 중으로 오인하지 않는다.
5. 홈에는 오늘 목표가 있는 참여 챌린지를 표시한다. 144px 고정 너비 카드, 컬러 배지, 내부 가로 스크롤, 남은 방향 화살표를 적용했다. 추가 검수 결정에 따라 오늘 완료한 카드도 유지한다. 공식은 '했어요'로 기존 SELF 인증 API를 호출해 승인 성공 후 '달성'으로 표시하고, 맞춤은 해당 날짜 전체 복용 기록에 따라 '미달성/달성'을 표시한다. 되돌리기는 재조회 후 반영한다. 한국 날짜가 바뀌면 공식/맞춤 참여 데이터를 다시 조회한다.
6. 챌린지 마이 하단의 중복 공식 둘러보기/맞춤 새로 참여하기 링크를 제거했다. 상단 둘러보기 경로는 유지한다.
7. 챗봇 플로팅 버튼은 기존 병아리 알약 이미지 `/images/default-profile.png`를 사용한다. 추가 검수에서는 이미지 여백을 잘라 병아리를 확대하고, 60px 청록색 말풍선 테두리·작은 채팅 표시·입체 그림자를 적용했다. 반복 모션은 없다.
8. 공식 상세의 모집을 모집기간으로 변경하고 한국 날짜로 `년 월 일 ~ 년 월 일`을 표시한다.
9. 둘러보기는 전체/공식/맞춤 필터를 제공한다. 초기값은 전체다. 추가 검수에서 OS native 목록의 너비 이탈을 수정하기 위해 공통 Radix Select로 교체하고 팝업을 트리거 폭에 맞췄다. 모집 일정이 없는 맞춤 추천은 임의 날짜를 만들지 않고 상시로 표시한다.
10. 챌린지 상세·참여·대상 선택 헤더는 공통 Header를 사용하며 긴 제목, 뒤로가기, 기존 부제와 동작을 보존한다.
11. 홈/영양제 둘러보기에서 현재 전시할 랭킹이 없거나 상품이 0개면 타이틀과 카드, 로딩/실패 안내를 모두 숨긴다. 유효한 상품이 있는 랭킹과 검색은 유지한다. 전시기간 판정은 기존 서버를 따른다.
12. 스크롤 달력의 가운데 선택 네모에 primary 색 2px 테두리를 적용했다. 오늘 네모 안에만 '오늘'을 표시하며 날짜 제목 옆 표시는 제거했다. 완료 배경색, 가운데 확대, 날짜별 기록 연동은 유지한다.
13. 맞춤 추천과 대상 선택 화면의 하단 '챌린지로 돌아가기'/'맞춤 챌린지로 돌아가기' 링크를 제거했다. 상단 뒤로가기와 확인 창의 취소 동작은 유지한다.
14. PC 비로그인 홈의 랭킹 미전시 시 비어 있는 2열과 가운데 배너가 어긋나는 문제를 수정했다. 비로그인 카드들은 최대 640px 읽기 폭의 단일 열로 정렬하고, 로그인 홈의 기존 2열 배치는 유지한다.

### 영양제 맞춤 카드의 의도적 예외

영양제 추천의 existingParticipationId는 개별 제품 대상 정보이며 동일 제품이라도 다른 묶음으로 참여할 수 있다. 전체 템플릿을 비활성화하면 유효한 새 조합 선택을 막으므로 영양제 맞춤 추천 카드는 선택 가능하게 유지했다. 이것까지 막는 정책은 별도 검수 결정이 필요하다.

## 검증

- 타입 검사 `tsc --noEmit`: 통과.
- Vite production build: 통과. 기존 500kB 초과 번들 경고는 남아 있다.
- API fixture 모드 최종 통합 78개: 통과.
- 최종 높이 전환/터치/선택 25개: 통과 (위 묶음 재검증).
- 반응형/클레이/챗봇 모션/공개 랭킹 mock 회귀 24개: 통과.
- 챌린지 기존 흐름 39개와 카탈로그/로딩/좁은 화면 11개: 통과.
- 중복 제외 위 선택 회귀는 152개다. 전체 테스트 스위트 또는 실제 사용자 DB·메일 발송 검증은 아니다.
- 추가 달력 표시/링크 제거 후 날짜 스크롤·카탈로그 회귀 31개: 통과 (위 카탈로그 테스트 일부와 중복). 신규 기대 동작 3개가 수정 전 실패하는 것도 확인했다.
- 실패를 먼저 재현한 주요 항목: 하단바 화면 이탈, 복약 시각 노출, 미전시 랭킹 표시, 오늘 목표 필터, 가로 이동, 자정 갱신, 로딩 높이의 즉시 점프.
- 리뷰에서 발견한 자정 갱신 누락·로딩 높이 차이·로컬 배지 fallback 경로를 수정했다.
- 별도 기존 scrollbar 점검의 데스크톱 개인정보 표 테스트 1개는 표가 가로폭에 들어오는데 overflow를 필수로 기대하여 실패한다. 새 하단바 CSS를 비활성화해도 동일함을 확인했고 이번 기능 수정에는 포함하지 않았다.

## 직접 검수

- 홈 → 오늘 챌린지 좌우 스와이프/화살표, 복약 완료 및 되돌리기.
- 챌린지 둘러보기 → 전체/공식/맞춤 필터, 회색 참여중 카드, 모집기간, 상세/재참여.
- 긴 복약/영양제/마이 화면 → 하단바와 끝의 버튼 접근.
- 복약 카드 펼침 → 시간대만 표시, 연필 수정 → 실제 시각 유지.
- 네트워크 속도를 낮추고 홈/챌린지/복약 진입 → 빈 회색 상자 대신 상태 안내 및 부드러운 전환.
- 영양제 랭킹 미등록/기간 종료/제목만 등록 → 영역 미노출.
- 챌린지 달력 → 오늘 네모 안 글자, 가운데 네모의 진한 테두리, 좌우 스크롤 후 날짜별 기록 변경.
- 맞춤 추천/대상 선택 → 하단 돌아가기 링크 미노출, 상단 뒤로가기 유지.
