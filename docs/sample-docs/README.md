## 이걸로 확인할 것

1. **복용일수 추출** — 환자1 Rivaroxaban 14일이 뽑히는지. 퇴원일 + 복용일수 = 활성 기간 계산의 입력값이라 이게 안 나오면 홈 노출 로직이 못 돈다
2. **날짜 파싱** — 입원일/퇴원일/외래 예약일 3종이 섞여 있음. 퇴원일만 정확히 골라내는지
3. **약 테이블** — 약품명 / 용량 / 횟수 / 일수 4필드가 행 단위로 유지되는지 (봉투는 시간대 블록, 기록지는 목록 → 형식이 다름)
4. **의학용어 순화** — `Rt Femur head Fracture, closed`를 "오른쪽 넓적다리뼈 머리 부분이 부러졌고 피부는 찢어지지 않은 상태"처럼 풀어주는지. `WBAT`, `POD#3` 같은 약어를 모른다고 하지 않고 추측해서 틀리는지도 봐야 함
5. **여러 장 묶기** — 환자2 두 장이 진료기록 1건으로 합쳐지는지, 2장에만 있는 금기사항이 안내에 반영되는지
6. **신뢰도 구간** — `_rough` 버전에서 잘린 가장자리·그림자 영역 항목의 confidence가 실제로 낮게 나오는지. 낮게 안 나오면 OCR 확인 화면의 배지가 무의미해진다

## 중요 — 이 이미지만으로 정확도를 판단하지 마세요

`_rough`의 그림자·왜곡은 실제 촬영 환경보다 **약합니다**. 실제 문서에는 접힌 자국, 도장 겹침, 손글씨 메모, 형광펜, 스테이플 구멍, 흔들림, 조명 반사가 있습니다.

**이 파일들을 A4로 인쇄해서 폰으로 찍은 사진을 함께 테스트하세요.** 합성 이미지만으로 측정한 OCR 정확도는 실제보다 낙관적으로 나옵니다.
