## 충돌 해결

- 로그인 순차 등장과 포커스 처리를 유지하면서 재전송 중복 방지 및 비밀번호 재설정 바텀 시트를 결합했다.
- 챌린지의 공식/맞춤 목록, 일 단위 진행률, 배지, 복약 저장/되돌리기 자동 연동을 유지했다.
- 챗봇 마크다운과 입력창 위 안전/AI 안내를 보존하고 기존 모션 스타일을 결합했다.
- 복약/영양제 시간대 스와이프와 선택 슬라이드를 유지하면서 최신 완료 요약 및 저장 처리를 반영했다.
- OCR 펼침/수정 UI를 유지하며 낮은 신뢰도만 확인 대상으로 표시하는 최신 정책을 반영했다.
- #369의 넓은 공통 dialog 규격이 #392까지 늘리지 않도록 재설정 시트만 최대 390px로 제한했다.
- #384 제목 DOM 변경에도 홈 카드 제목 색이 유지되도록 선택자를 보정했다.

## 후속 UI 작업

- 390×600의 짧은 화면에서는 챗봇 플로팅 버튼이 복약 카드 오른쪽 일부를 가릴 수 있다. #369 후속 배치 정리 대상으로 남긴다.
- 네이티브 스와이프 테스트는 복약 버튼의 실제 노출된 중앙 영역에서 시작하도록 했으며, 터치 시작점이 해당 버튼인지 검사한다. 이는 플로팅 버튼 겹침 자체의 해결을 의미하지 않는다.
- 리뷰에서 추가 고신뢰도 차단 이슈는 발견되지 않았다. main으로의 역방향 병합 및 PR 생성은 이번 작업에 포함하지 않는다.
