# 직접 상호작용 쌍 메타데이터 준비도

## 목적

`interaction_pair_keys`는 두 성분이 한 문서나 한 청크에 같이 등장했다는
사실이 아니라, 해당 출처가 두 성분의 관계를 직접 설명한다는 사실을 나타낸다.
이 문서는 새 Qdrant 컬렉션을 만들기 전 메타데이터의 근거 경계를 기록한다.

## 확인 결과

| 조합 | 출처 상태 | 적용 상태 | 이유 |
| --- | --- | --- | --- |
| 비타민 D–칼슘 | 식약처 건강기능식품공전 `1-3 비타민 D` (`mfds_supplement_code-72e61399c742b0e5`) | 유지 | `비타민 D는 칼슘과 인이 흡수되고 이용되는데 필요`라는 직접 관계 문장이 있다. 두 성분이 같은 청크에 있을 때만 키를 부여한다. |
| 칼슘–철분 | `Calcium and Iron Absorption – Mechanisms and Public Health Relevance` (`research_supplement_interactions-016c81c9a3e29ebd`) | 유지 | 칼슘 섭취와 철 흡수의 관계를 직접 다룬 문헌이다. |
| 마그네슘–아연 | 없음 | 미적용 | 원료별 마그네슘·아연 문서는 각각 존재하지만, 현재 매니페스트·전처리 릴리스에서 두 성분의 직접 병용·흡수·주의 관계를 입증하는 검수 출처는 찾지 못했다. |

## 청크 적용 규칙

1. 문서 ID가 사람이 검수한 주석 매니페스트에 있어야 한다.
2. 청크 텍스트에 왼쪽·오른쪽 엔터티의 별칭이 모두 있어야 한다.
3. 한 성분만 있는 청크, 관련 없는 문서, 성분 목록의 우연한 동시 등장은 키를 받지 않는다.
4. 직접 근거가 없는 마그네슘–아연 질문은 일반 상호작용 근거로 단정하지 않고, 근거 부족 정책을 사용한다.

## 릴리스 게이트

- 이 단계에서는 매니페스트의 임상 주석을 추가·변경하지 않았다.
- OpenAI 임베딩 API 호출, Qdrant 컬렉션 생성, 활성 컬렉션 교체는 수행하지 않았다.
- 마그네슘–아연의 직접 관계 출처를 새로 확보·검수하기 전에는 해당 `interaction_pair_key`를 새 컬렉션에도 넣지 않는다.
- 추후 후보 문헌이 생기면 원문 대조 → 문서 ID·별칭 검수 → 청크 단위 테스트 → 새 불변 컬렉션 A/B 평가 → 별도 승인 순서로 진행한다.
