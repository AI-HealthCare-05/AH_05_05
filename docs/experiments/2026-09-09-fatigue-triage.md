# 피로 관련 대화형 문진 실험 기록

## 상태

`SUCCESS` — 피로 표현은 검색·LLM·제품 추천보다 먼저 결정론적 문진으로 전환되며, 긴급 신호가 있으면 제한된 긴급 도움 안내로 분기한다.

## 가설

“요즘 피곤해”처럼 정보가 부족한 질문에 특정 영양제를 바로 제시하는 대신, 위험 신호·복용 제품·생활 맥락을 먼저 확인하면 의료적 처방이나 추천으로 넘어가지 않으면서 다음 안전한 대화를 만들 수 있다.

## 변경

- `FatigueConversationPolicy`가 피곤·피로·무기력 등 피로 표현을 감지한다.
- 흉통, 숨참/호흡곤란, 실신, 의식저하, 마비, 검은 변, 토혈 같은 긴급 신호가 함께 있으면 `URGENT`로 분기한다.
- 일반 피로는 다음 정보만 질문한다.
  - 시작 시점·지속 기간
  - 급한 증상 여부
  - 현재 복용 약·영양제와 최근 변경
  - 수면·식사·음주·생활 변화
- 일반 피로는 `GENERAL_GUIDANCE`, 긴급 신호는 `RESTRICTED`로 반환한다. 두 경로 모두 Retriever·답변 LLM을 호출하지 않는다.

## 검증

| 사례 | 결과 |
| --- | --- |
| `요즘 계속 피곤해요` | 추가 확인 항목 반환, 제품 추천·복용량·진단 문구 없음 — PASS |
| `피곤하고 숨이 차며 실신할 것 같아요` | 119/응급의료기관 도움 경계, 영양제 안내 없음 — PASS |
| `타이레놀 복용법` | 피로 정책 미적용 — PASS |
| UseCase 통합 | Retriever·LLM 전 조기 반환, 안전 Trace만 기록 — PASS |

## 제한

- 이 정책은 피로 원인을 추정하거나 질환을 분류하지 않는다.
- 긴급 신호 목록은 응급 여부의 의료적 판정이 아니라 즉시 도움을 권하는 보수적 분기다.
- 다단계·재개 가능한 문진 상태는 저장하지 않는다. 실제 문진이 장기화되거나 사람 개입이 필요해지면 LangGraph ADR의 재검토 기준이 된다.
