## 확인된 실패 원인

1. `찰 영양제`처럼 대상이 확정되지 않은 질문에서도 BM25가 “영양제·기능” 같은 일반 단어만 겹치는 문서를 반환했습니다.
2. `처음 보는 약` 질문에서도 일반적인 주의사항 표현이 겹치는 여러 약물백과 문서를 반환했습니다.
3. 칼슘–철분 질문에서는 정답 문서 외에 `Supplemental Zinc Lowers Measures of Iron Status...` 문서가 섞였습니다. 원문은 아연–철분 연구지만 기존 v2 청크에 칼슘–철분 메타데이터가 잘못 부여된 데이터 품질 문제입니다.
4. 당시 평가 계약은 “근거가 없어야 하는 질문에 문서가 반환되는 것”을 실패로 계산하지 않아, 이를 후속 평가 계약에 추가했습니다.
