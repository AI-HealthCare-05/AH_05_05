# 근거 부족 시 대안 가이드 실험 기록

## 상태

`SUCCESS` — 근거가 없는 의약품·영양제·상호작용 질문에서 실제 약물 사실을 추가하지 않고, 확인 범위·일반 안내·공식 확인 경로·의료진 질문 체크리스트를 일관되게 제공한다.

## 가설

검색 실패를 단순한 “알 수 없음”으로 끝내는 대신, 확인하지 못한 범위를 명확히 하고 사용자가 다음 행동을 선택할 수 있게 하면 의료적 환각 없이도 유용한 안내가 가능하다.

## 기준선

기존 제한 응답은 “근거를 찾지 못했다”와 “제품명이나 성분명을 확인해 달라”는 문장 중심이었다. 공식 확인 경로와 의료진에게 전달할 정보가 구조화되어 있지 않았다.

## 변경

`EvidenceGapGuidanceBuilder`를 추가해 아래 여섯 부분을 결정론적으로 구성한다.

1. 확인된 범위: 승인 규칙·검색 근거에서 직접 근거를 확인하지 못한 사실
2. 일반 안내: 시작·중단·용량 변경·병용 판단을 임의로 하지 않기
3. 알 수 없는 범위: 근거 부재가 문제 없음의 결론은 아니라는 경계
4. 공식 확인 경로: 의약품안전나라, 식품안전나라
5. 의료진·약사에게 확인할 내용: 제품·성분·함량·시점·현재 복용 목록·취약군 정보
6. 안내 한계: 진단·처방 대체 금지

상호작용, 의약품, 영양제, 알 수 없는 대상에 따라 공식 경로와 대상 표현만 바뀐다. 이 빌더는 엔터티 미확인 또는 검색 근거 미확인으로 제한된 응답에만 연결했다.

## 검증

| 사례 | 기대 결과 | 결과 |
| --- | --- | --- |
| 아스피린–오메가3 상호작용 근거 부족 | 두 공식 확인 경로와 조합 표식, 안전 단정 없음 | PASS |
| 영양제 근거 부족 | 식품안전나라와 확인 체크리스트, 효능·복용법·용량 생성 없음 | PASS |
| 대상 미확인 일반 질문 | 여섯 부분의 공통 가이드와 제한 상태 | PASS |

도메인 및 챗 통합 테스트 `50 passed`로 확인했다. 전체 AI Worker 회귀 검증은 커밋 직전에 별도로 실행한다.

## 실패 방지 경계

- 이 경로는 제품 효능, 상호작용 결과, 개인별 섭취량을 추론하거나 추천하지 않는다.
- “근거가 없다”를 “문제가 없다” 또는 “안전한 조합”으로 바꾸지 않는다.
- 정확한 근거가 이후 확보되면 기존 RDBMS/Qdrant 기반 답변 경로가 우선한다.
