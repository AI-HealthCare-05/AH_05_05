# 근거 커버리지 기반 1회 재검색 실험 기록

## 상태

`PARTIAL` — 결정론적 fixture에서 부족한 섹션에만 정확히 한 번 재검색해 근거 커버리지를 보완했다. 실제 Qdrant 고정 평가 세트의 P95와 근거 충실도를 다시 비교하기 전에는 기본 검색 경로의 확장 활성화를 확정하지 않는다.

## 가설

질문이 요구한 효능·복용법·주의사항·상호작용 중 일부가 제품 가이드와 첫 RAG 결과에 없을 때만, 이미 확정한 엔터티와 부족한 섹션 용어를 사용해 한 번 더 검색하면 임의 생성 없이 근거 커버리지를 높일 수 있다.

## 기준선

기존 경로는 첫 검색·제품 가이드·승인 규칙을 조합한 뒤, 부족한 섹션이 남아도 재검색하지 않았다. 따라서 예를 들어 효능만 검색되고 주의사항이 비면 해당 항목은 답변 근거에서 빠졌다.

## 변경

- `CoverageGapQueryExpander`는 확정된 `entity_names`와 부족한 섹션만 사용한다.
  - `FUNCTION`: `효능 기능성`
  - `DAILY_INTAKE`: `일일 섭취량 복용법`
  - `CAUTION`: `주의사항 이상반응`
  - `INTERACTION`: `상호작용 병용`
- 새 질의는 원 질문과 확정 엔터티를 유지하며 `alternate_queries`를 만들지 않는다.
- 재검색은 최대 한 번이다. 두 번째 결과도 부족해도 다시 호출하지 않는다.
- 첫 검색 실패 시 재검색하지 않는다. 이미 확보한 근거를 유지하고 안전 제한 상태를 보존한다.
- 합칠 때는 `content_hash` 기준으로 중복을 제거하고, 기존 제품 가이드·승인 규칙을 다시 조회하지 않는다.

## 검증

| 사례 | 첫 검색 | 재검색 | 최종 커버리지 | 결과 |
| --- | --- | --- | --- | --- |
| 마그네슘 효능·주의사항 | `FUNCTION`만 | `마그네슘 주의사항 이상반응` 1회 | `FUNCTION`, `CAUTION` | PASS |
| 마그네슘 기능성 | `FUNCTION` 충족 | 없음 | `FUNCTION` | PASS |
| 재검색 횟수 제한 | 부족 섹션이 남아도 | 최대 1회 | 호출 수 최대 2 | PASS |

`rag.coverage_retry` Trace span에는 질문·본문 없이 `attempted`, `query_count`, 부족 섹션 전후, `rag_unavailable`만 남긴다. `KnowledgeRetrievalResult.coverage_retry`에도 같은 구조화 관측값을 보존한다.

## PARTIAL 이유와 다음 측정

추가 검색은 정확도를 우선해 의도적으로 지연시간을 늘릴 수 있다. 실제 `medication_knowledge_full_v6`에서 동일 고정 질문으로 다음을 비교해야 한다.

- 요청 섹션 커버리지와 근거 충실도
- 잘못된 엔터티 혼입률
- 1차 검색 대비 P50/P95 지연시간
- 재검색이 필요한 질문 비율

P95가 과도하게 늘거나 잘못된 대상이 증가하면 이 경로는 기본 활성화하지 않고, 경로별 조건을 더 좁힌다.
