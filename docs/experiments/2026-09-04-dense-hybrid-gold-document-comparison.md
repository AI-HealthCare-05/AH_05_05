# Dense·BM25·Hybrid 검색 비교 실험

- 판정 원칙: 속도보다 정확도 우선
- 최종 결정: `KEEP_DENSE`
- 차단 사유: NO_ACCURACY_IMPROVEMENT
- 경고: 없음

## 실험 근거

- 목적: 동일한 사용자 질문과 정답 문서 계약으로 Dense와 Hybrid 검색을 비교하여, 관련 근거를 더 앞에 배치하면서 다른 약·성분 문서를 섞지 않는 검색 방식을 선택한다.
- 채택 기준: Hybrid의 Hit@5 또는 MRR이 Dense보다 개선되고 Recall@20·출처 정확도·근거 커버리지가 하락하지 않으며 잘못된 대상 혼입과 중복 검색이 늘지 않을 때만 Hybrid를 활성화한다. 속도는 정확도 조건을 통과한 뒤 운영 경고 지표로 판단한다.

| 지표 | 선정 이유 |
|---|---|
| recall_at_20 | 관련 문서가 재정렬 전 후보 20건 안에 들어오는지 확인한다. |
| hit_at_5 | 최종 답변 생성에 전달되는 상위 5건에 정답 근거가 포함되는지 확인한다. |
| mrr | 첫 정답 문서가 사용자 답변에 사용되기 좋은 앞 순위에 배치되는지 확인한다. |
| source_accuracy | 선택된 문서 중 질문 대상과 직접 관련된 골드 문서의 비율을 확인한다. |
| evidence_coverage_rate | 사용자가 요청한 효능·복용법·주의사항·상호작용 근거가 빠짐없이 검색되는지 확인한다. |
| wrong_target_mixing_count | 이름이나 주제가 비슷한 다른 약·성분의 근거가 섞이는 안전성 오류를 측정한다. |
| duplicate_retrieval_rate | 같은 청크가 반복되어 근거 다양성과 답변 품질을 낮추는지 확인한다. |
| search_p95_ms | 정확도 조건을 통과한 검색 방식의 최악 구간 지연이 운영 가능한지 감시한다. |
