# 신규 영양제 등록 안전성 점검 실험 기록

## 상태

`SUCCESS` — 등록 전 입력만으로 성분 중복·동일 단위 총량·승인 상호작용 규칙·취약군 상태를 결정론적으로 판정한다. LLM은 이 상태를 계산하거나 변경하는 경로에 없다.

## 가설

영양제 등록은 자연어 답변보다 먼저 구조화된 안전 상태를 계산해야 한다. 특히 성분명·함량·단위가 불완전하면 안전하다고 추정하지 않고 `UNKNOWN`으로 보류해야 한다.

## 입력·판정 계약

- 입력: 신규 제품 성분 목록, 현재 복용 성분 목록, 승인된 상호작용 규칙, `YES / NO / UNKNOWN` 위험 프로필
- `RESTRICTED`
  - 기존 성분과 신규 성분이 중복됨
  - 신규·기존 성분 조합이 승인 규칙과 일치함
  - 위험 프로필 중 하나가 `YES`임
- `UNKNOWN`
  - 성분의 함량 또는 단위가 비어 있음
  - 동일 성분의 단위가 달라 합계를 계산할 수 없음
  - 위험 프로필 중 하나가 `UNKNOWN`임
- `SAFE`: 위 제한·미확인 조건이 없고 모든 총량을 같은 단위로 계산할 수 있음

이 결과는 용량 적정성·복용 지속 여부를 의료적으로 판정하지 않는다. 총량은 계산 가능한 입력값을 정리하는 정보일 뿐, 상한섭취량 또는 개인별 권고 결론이 아니다.

## 검증

| 사례 | 결과 |
| --- | --- |
| 마그네슘 200 mg 복용 중 100 mg 등록 | 중복 성분, 총 300 mg, `RESTRICTED` — PASS |
| 와파린 복용 성분과 비타민 K 등록, 승인 규칙 존재 | 규칙 ID 보존, `RESTRICTED` — PASS |
| 오메가3 함량·단위 누락 | `AMOUNT_OR_UNIT_MISSING`, `UNKNOWN` — PASS |
| 수술 예정 `YES` | `HIGH_RISK_PROFILE`, `RESTRICTED` — PASS |

## 연결 범위

이번 단계는 순수 도메인 평가기와 DTO·인터페이스 계약만 추가했다. 실제 등록 화면/API는 이 결과를 먼저 호출해 경고·추가 입력 요청을 표시하고, LLM은 결정된 상태에 대한 설명만 생성해야 한다.
