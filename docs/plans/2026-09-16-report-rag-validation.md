## 활성화 전 조건

현재는 기존 경로가 기본이다. 실제 연결 시험 한 번으로 출력 품질 동등성을 보장하지 않는다.
대표 약 단독/영양제 단독/혼합/자료 없음 사례에서 기존 핵심 정보 누락이 없는지,
문장마다 원문이 뒷받침하는지, 중요한 안내를 잃지 않는지 비교한 뒤 활성화한다.
활성화 후에는 PARTIAL 비율, 검증 완료 안내 수, 검색 수, 생성 시간과 실패를 관찰한다.
잘못된 대상·수치·인용 또는 핵심 경고 누락이 확인되면 플래그를 끄고 기존 경로로 돌아간다.
운영 활성화 책임자와 관찰 기간은 아직 정하지 않았다.

## 후속: 출력 검토 후 보완 (2026-09-16)

위 활성화 전 기록과 별개로, 사용자 요청에 따라 로컬 RAG는 이미 활성화된 상태다.

## 실제 등록 구성의 검색 누락 복구 및 화면 재검증

앞선 가상 시험은 실제 복합제품의 긴 검색어를 대표하지 못했다. 약 12개와 복합 영양제 2개를 구성한 `commercial-stack` 시험에서 9개 그룹 검색 모두 근거 0건을 재현했다. 여러 제품과 8개 성분을 섞은 검색어는 최고 유사도가 약 0.617로 기존 0.65 기준에 미달했다.

- 근거가 없는 섹션은 서버가 이미 알고 있는 성분 별칭만 개별 재검색한다. 원래 유사도·공개 출처·정확 인용·대상 검증은 완화하지 않았다.
- 성분 검색은 보고서 전체에서 유형+성분별로 공유하며 최대 24회 추가, 동시 3회로 제한한다. 기존 그룹 검색 최대 9회와 합치면 최대 33회다. 기존 전체 제한 시간과 취소 정리를 유지한다.
- DB 링크 또는 정확 이름 일치에서 얻은 `ActiveMedication.interaction_names`가 보고서 조립 시 사라지던 문제를 수정했다. `current_stack.ingredient_aliases`를 통해 RAG까지 보존하며 제품명으로 성분을 추정하지 않는다.
- 최종 표시 문장에서 `AST상승`, `(소아)복용`, `천공(뚫림)과민증상`의 공백을 보정했다. 원문 자료와 제품명은 수정하지 않는다.

직접 검증:

- 같은 `commercial-stack`의 GPT-4o/Qdrant 시험: **49.47초, 17회 검색(성분 8회), 검증 카드 2개·출처 2개**. 이 시간은 재현 시험이며 실제 계정 보고서 생성 시간을 측정한 것은 아니다.
- 기존 로그인 탭에서 같은 등록 목록으로 실제 보고서를 다시 생성했다. **복용약 12종·영양제 2종 유지**, 비타민 C/D 추가 주의사항 2건 표시, 펼친 근거에서 식약처/식품안전나라와 정확 인용문 확인. 화면 캡처로 잘림 없이 표시됨을 확인했다.
- 실제 약 상세에서 `AST 상승`, `ALT 상승`, `(소아) 복용`, `천공(뚫림) 과민증상` 표시를 확인했다.
- 관련 테스트 **503 passed (13.57s)**, 변경 Python Ruff 통과, `git diff --check` 및 로컬 fastapi healthcheck 통과. 독립 읽기 전용 리뷰의 차단 지적 없음.

남은 한계: 음식·생활 섹션의 추가 RAG 안내는 이번 목록에서 검증된 근거가 없어 미확인이다. 기존 약 안내는 3종이며 나머지 9종의 제품 확정/자료 부족은 해결된 것으로 표시하지 않는다. 현재 안내가 없는 것을 안전하다는 의미로 바꾸지 않는다. AWS 배포·커밋·push는 하지 않았다.

## 2026-09-17: 미확정 제품의 성분 공통 안내 연결 — 코드 검증, 실제 자료 제한 확인

- 일반 정/캡슐 이름에서 용량·제형을 제외한 후보가 DB 성분명과 정확히 일치할 때만 보조 연결한다. 이 fallback은 정규화된 canonical_name까지 같아야 한다. 특정 브랜드로 제품을 확정하지 않는다.
- 제품 안내 연결이 없는 약은 `ingredient_only`로 검색·검증한다. 성분 태그가 정확히 맞는 공통 문서만 허용하고 제품 라벨, 다른 제품 태그, 복용량·횟수·간격 안내는 제외한다. 카드가 실제 검증된 경우에만 제품 미확정/성분 공통 안내 문구를 붙인다.
- 신규 회귀 사례의 실패를 먼저 재현한 뒤 수정했다. 관련 테스트 432개 및 변경 Python Ruff/포맷 검사 통과. 독립 검토에서 추가로 발견한 '한 알', '두 차례' 우회도 회귀 테스트와 함께 차단했으며 재검토의 잔여 차단 지적은 없다.
- 실제 GPT-4o/Qdrant `generic-medication` 시험은 **검증 카드 0개**로 미완료다. 문서 `kpicia_drug_encyclopedia-33898a903b6cbca7`은 검색되지만 `access_scope=DEMO_RESTRICTED`, `ingredient_names=[]`, `study_population=UNKNOWN`이다. 공개 근거 필터를 완화하거나 벡터 DB 메타데이터를 변경하지 않았다.
- 남은 조건: 보고서에 사용할 수 있는 권한이 확인된 성분 공통 근거를 준비하고 정확한 성분/대상 메타데이터로 색인한 뒤 재검증해야 한다. 자료가 있는데도 제품명 후보와 연결되지 않는 문제와, 자료 공개 범위 때문에 사용하지 못하는 문제를 구분한다.
- 실행 중 컨테이너에는 소스 마운트가 없어 이번 로컬 코드 수정이 자동 반영되지 않는다. 컨테이너 재빌드, AWS 배포, 커밋·push는 하지 않았다.

### 후속: 사용자 승인에 따른 데모 자료 보고서 사용

- 2026-09-17 사용자가 데모용 자료를 보고서에 사용하도록 명시적으로 요청했다. 보고서 출처 registry와 청크 필터에서 PUBLIC/DEMO_RESTRICTED를 모두 허용한다. 원래 자료 태그는 유지하고 출처 미확인/색인 금지 자료는 제외한다.
- 기존 약물백과의 빈 성분 태그는 문서 제목의 정확한 성분명 및 괄호 안 영문명과 drug_names가 일치할 때만 보완한다. 브랜드 접두어/다른 제품 태그는 거부한다. 약물백과에 한해서 UNKNOWN 연구 대상 분류를 허용하되 동물 연구와 일반 연구논문의 UNKNOWN은 계속 거부한다.
- 관련 테스트 436개와 Ruff 통과. 실제 GPT-4o/Qdrant 첫 생성은 인용·용량 검증에서 카드 0건이었다. 후속 진단 실행은 15.16초에 성분 공통 안내 3개/정확 인용 출처 3개를 생성했다. 같은 코드에서도 모델 출력에 따라 안내 수가 달라지므로 이 수치는 고정 보장값이 아니다. 제품명은 확정하지 않았고 잘못된 인용 2건과 용량 안내 1건은 차단했다.
- 컨테이너 재빌드·AWS 배포·커밋·push는 하지 않았다. 로컬 소스 및 직접 실행 검증 결과이며 실행 중인 웹 보고서에 자동 적용된 것으로 표시하지 않는다.

### 후속: 실제 다중 등록 보고서에서 성분 근거 누락 수정

- 실행 중인 fastapi의 소스 hash와 RAG 활성화를 확인했다. 이후 실행 환경에는 ai_worker 소스 마운트가 있어 기존의 '재빌드 필요' 상태와 달랐다.
- 실제 약 12종/영양제 2종의 전체 Core 생성 경로에서 아세트아미노펜 성분 연결은 정상이나 안내 0건을 재현했다. 계측 결과 검색 근거 21개 중 아세트아미노펜 근거 2개가 있었지만 전역 점수순 상위 6개 제한으로 모두 제외됐다. DTO나 화면에서 제거된 것이 아니다.
- 검증된 근거를 등록 대상별로 먼저 배정한 뒤 점수순으로 채운다. 섹션 근거 한도는 대상 수에 따라 6~18개로 제한하고 문서당 2개 제한을 유지한다. 다른 대상 근거가 있어도 근거 없는 대상은 성분별 보조 검색을 시도한다.
- 누락 회귀 테스트의 실패를 먼저 확인한 뒤 수정했다. 관련 테스트 437개 및 Ruff 통과. 동일 전체 Core 재실행 18.31초, 최종 lifestyle 응답에 아세트아미노펜 성분 공통 주의 카드 및 정확 인용 출처가 포함됨을 확인했다. 모델 안내 수는 고정값이 아니다.
- 로컬 API 서버만 재시작하여 새 모듈을 읽도록 한다. DB 데이터 수정, 보고서 메일 발송, Git 커밋·push는 하지 않는다. 기존 화면에 보관된 보고서는 새로 생성해야 한다.

### 후속: 검증된 안내 개수 제한 제거

- 사용자가 주의사항·가이드의 최대 개수 제한 없이 표시하도록 요청했다. `_ClaimsPayload`/파서의 18개 상한, 섹션 카드 6개 상한, 최종 카드 18개 절단을 제거했다. 검색 후 검증된 근거의 문서당 2개 및 전체 6~18개 절단도 제거했다.
- 중복 제거와 출처/정확 인용/대상/용량 검증은 유지한다. 검색 쿼리 수, 검색 한 번당 결과 수, 전체 실행 시간, 모델 문맥·출력 토큰 한계는 여전히 존재하므로 DB 전체 내용의 완전한 추출을 보장하는 변경은 아니다.
- 기존 상한을 넘는 7/19/25개 안내가 모두 반환되는 회귀 시험과 8개 근거(동일 문서 3개 포함)가 모두 전달되는 시험을 통과했다. 관련 테스트 440개와 Ruff 통과.
- 실제 약 12개·영양제 2개 Core 재실행: 37.4초, 전체 추가 안내 5개(그중 RAG 4개), 아세트아미노펜 관련 2개. 모델이 생성·검증한 수이며 새로운 최대 개수가 아니다. 로컬 API만 재시작하고 DB 변경·메일 발송·커밋·push하지 않는다.
