# #252 사용자 피드백 재검수

기준: 2026-09-05 사용자 피드백 1~14 및 후속 수정 요청.

| 번호 | 확인 기준 |
| --- | --- |
| 1 | OCR 이미지 제목은 `약봉투`. 전처리 용어 제거. |
| 2 | 시간 선택 버튼 외에 선택한 시간 요약/중복 선택 안내 없음. |
| 3 | `아직 안 먹었어요`로 등록 가능하며 복용 완료 기록을 만들지 않음. |
| 4 | 등록 중 시간 설정에서 뒤로 가면 수정 가능한 OCR 결과 복원. 재확정은 기존 회차 갱신. 등록 완료·복용 기록·메모가 있는 회차는 재등록 수정 차단. |
| 5 | 마이 알림 토글 OFF 트랙은 `bg-input`으로 배경과 구분. |
| 6 | 홈 펼친 약마다 같은 처방 날짜를 반복하지 않음. |
| 7 | 홈 처방 제목에 별칭 표시. 접근성 이름에도 별칭과 날짜 포함. |
| 8 | OCR·시간 설정·홈에서 약명에 이미 있는 동일 함량을 다시 붙이지 않음. 원본 값과 별도 함량 정보는 유지. |
| 9 | OCR 누락 필드 또는 아직 확인하지 않은 낮은 신뢰도 항목을 표시. 조제일 직접 수정 후 확인 필요 배지 해제. |
| 10 | 다른 처방 목록 토글의 보이는 문구는 `펼치기`/`접기`. 스크롤바 공간 고정. |
| 11 | 처방 헤더의 화살표 위치는 상세 펼침 전후 동일. |
| 12 | 저장 직후 흰색 비활성 → 다른 처방 선택 시 활성 → 완료 처방 선택 시 되돌리기. |
| 13 | 약 더보기 후 아래쪽 접기 문구 없이 화살표만 표시. 접근성 이름은 유지. |
| 14 | 영양제 선택 저장·전체 저장·되돌리기·실패 재시도. 현재 시간 기준 한 시간대만 표시. |

후속 요청: 영양제 내부 `오늘의 영양제` 제목/`개별 선택` 문구 제거. 메모와 후기 입력창을 분리하고 다른 기록을 보존.

## 검증 범위

- 브라우저 테스트와 캡처는 375×812 뷰포트의 실제 프런트엔드에 API 응답 fixture를 제공한 결과이며, 사용자 계정의 운영 데이터 캡처가 아니다.
- 관련 회귀 테스트: `home-medication-compression`, `home-supplement-doses`, `home-figma-overhaul`, `supplement-record-editor`, `medication-registration-flow`, `ocr-strength-display`.
- 서버 수정은 OCR 등록 중 재편집에 한정한다. 새 마이그레이션이나 사용자 DB 초기화는 요구하지 않는다.
- 최종 사용자 확인은 `feature/252`에서 실제 OCR 업로드 → 시간 설정 → 뒤로가기 → 약명 수정 → 재저장 및 영양제 복용/되돌리기를 진행한다.
