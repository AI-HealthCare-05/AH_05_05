# #578 복약 메모 날짜·시간 표시

- 기준 main: `6f0f5fd`, 독립 브랜치 `feature/578`.
- 원인: 공통 DateInput의 datetime-local 대체 입력창이 내부 ISO 문자열을 화면에 그대로 출력했다.
- 변경: 표시값은 `2026-09-17 08:00`, 부모 폼/onChange/저장 값은 `2026-09-17T08:00`으로 분리한다. 달력 초안·취소·적용·날짜 범위 제한·24시간 입력 정책은 유지한다.
- 날짜 전용 입력은 변경하지 않는다. 직접 입력 시 ISO 또는 공백 형태 모두 기존 네이티브 입력 기준으로 검증·정규화한다.
- 기존 E2E의 화면 표시 기대값만 공백으로 갱신했다. API 요청의 ISO 기대값과 테스트 입력은 유지한다.
- 수정 전 신규 회귀가 실제 `T` 표시로 실패함을 확인했다. 수정 후 표시·달력 취소·공백 직접 입력·저장 ISO 값 검증을 Chromium/WebKit에서 수행했다.
- 실제 앱 + 로컬 합성 데이터 검증이며 운영 DB·API, 실기기, 전체 CI 검증은 아니다.
- 캡처/테스트 결과: `artifacts/578-note-datetime/`.
- 검증(2026-09-18): TypeScript 통과. 전체 달력 22건 실행에서 19 통과, 미갱신 캡처 기대값 2건 및 WebKit 회원가입 타임아웃 1건 발생. 캡처 기대값 갱신 후 해당 사례와 신규 저장 검증을 함께 재실행하여 6/6 통과(22개 고유 사례 모두 통과 확인). 최초 타임아웃을 없었던 것으로 처리하지 않는다.
- 최종 메모 캡처는 `verified/`의 `note-datetime-space.png`. 애니메이션 종료 후 촬영했다.
