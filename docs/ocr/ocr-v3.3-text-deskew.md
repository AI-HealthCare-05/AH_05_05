# 문자 줄 기울기 보정 후보 v3.3.1 — 2026-09-07

## 결론

906 로컬 복사본에 영상 기반 문자 줄 회전을 선택 후보로 추가했다. 기본값은 v3.1.3 그대로다.
같은 8장 비교에서 추출 결과 전체가 동일해 OCR 정확도 개선은 입증되지 않았다.
독립적인 단일 프로세스 재측정에서는 이미지별 3회 중앙값의 추가 전처리 시간이 평균 16.45ms,
최대 37.54ms였다. 목표 추가 지연 100~200ms 안에 들지만 이 표본·머신에 한정한 관측이다.

## 구현 범위

- `pipeline/text_deskew.py`: 최대 960px 분석 영상의 문자 후보와 수평 투영으로 ±20° 탐색.
- 최소 글자 높이·종횡비로 작은 점/가로 점선을 제외한다. 작은 글씨는 안전하게 건너뛸 수 있다.
- 점수 개선, 경쟁 각도 차이, 세로 영역 간 일치도를 통과한 경우만 회전한다.
- 기존 원근·조명 보정 뒤 실행하며 확장 캔버스와 4096px 상한을 사용한다.
- 원본 좌표 변환에 회전 행렬을 합성해 개인정보 마스크 좌표를 유지한다.
- OCR 추가 호출이나 LLM 호출을 하지 않는다. 불확실할 때 재시도 없이 기존 영상 유지.
- `OCR_PREPROCESS_VERSION=v3.3.1`로 선택 가능. `.env`와 실행 중 worker는 변경하지 않았다.
