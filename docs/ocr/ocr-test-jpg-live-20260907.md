# test.jpg 한 장 — v3.1.3 / v3.4.1 최종 결과까지 실측

## 범위와 실행 증거

사용자가 지정한 `810final/docs/문서 예시/복약안내/test.jpg`만 사용했다. 다른 이미지나 재촬영 종료 사례를 평균에 섞지 않았다.

- 실제 실행: **2026-09-07 14:43:54.708981 ~ 14:44:30.705843 KST**.
- 총 6회: v3.1.3 / v3.4.1 / v3.4.1 / v3.1.3 / v3.1.3 / v3.4.1 순서.
- 매 회차 새 공급자 클라이언트로 **실제 General OCR 1회 + 실제 OpenAI LLM 1회**를 호출했다. OCR 응답 재생이나 이전 결과 재사용은 없다.
- `perf_counter` 측정은 파일 읽기 직전부터 전처리·OCR·후처리·LLM·검증·최종 JSON 직렬화가 끝날 때까지다. UTC 시작/종료 시각도 별도로 기록했다.
- 각 회차의 UTC 시각 차이와 stopwatch 차이는 0.017~0.022ms다. 체크포인트 checksum과 실행 identity도 검증했다.
- **업로드 전송·큐 대기·DB 저장·브라우저 렌더링은 제외**한다. 사용자 화면에서 버튼을 누르고 결과를 보는 전체 지연이라고 주장하지 않는다.
- 두 버전은 **전처리 프로파일**이며, 후처리와 LLM은 최신 동일 코드 및 `gpt-4o-mini` 설정으로 고정했다. v3.1.3 개발 당시의 전체 앱 소스로 되돌린 비교는 아니다.

## 최종 정확도

6회 모두 **약 7개, 판독 가능 33필드 중 31개 일치 = 93.94%**다. 두 버전과 모든 반복의 최종 약품 5필드 목록도 문자 단위로 동일했다. 원문에 없거나 읽기 어려워 제외한 필드는 분모에 포함하지 않는다. 이는 조제일·문서 전체 성공률이 아닌 기존 약품 5필드 채점이다.

공통 미추출 2개는 소로펜정의 함량 `68.1mg`, 써스펜8시간이알서방정의 함량 `650mg`이다. 이번 실험은 비교 측정이며 해당 오류를 수정하지 않았다.

앞서 전체 16장의 서비스 평균 2~3초를 이 사진의 시간처럼 해석하면 안 된다. **이 사진을 OCR과 LLM까지 실제 처리한 시간은 이번 측정에서 5.261~7.216초**다.

## 파일과 검증

- 측정 스크립트: `scripts/benchmark_ocr_test_jpg.py`.
- 실행 증거: `.context/ocr-test-jpg-live-20260907/manifest.json`, `run-01-v3.1.3.json`~`run-06-v3.4.1.json`, `summary.json`.
- 측정 당시 스크립트 원본: 같은 폴더의 `measured-harness.py`. manifest의 harness SHA와 일치한다. 측정 후 유지보수 파일에는 `timezone.utc`를 동등한 `UTC` 별칭으로 바꾸는 Ruff 스타일 수정만 적용했다.
- 재사용 측정 도우미 테스트 4개 통과, 현재 스크립트 Ruff 검사·포맷 검사 통과.
- 독립 읽기 전용 검토에서 새 클라이언트·실제 호출 수·타이머 범위·시각 차이·실행 순서·점수·평균 집계를 대조했고 측정 주장에 영향을 주는 오류가 없었다.
- 원본 이미지·전체 OCR·환자 필드·모델 응답 원문을 새 결과 파일에 저장하지 않았다. 약품 5필드, 시각, 점수, 단계 시간 및 해시만 저장했다.
- 운영 코드·설정·worker·DB는 변경하지 않았다. 기존 변경을 보존했고 커밋·push하지 않았다.
