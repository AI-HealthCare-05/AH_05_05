# OCR 16장 · 전처리 3버전 평가 — 2026-09-07

## 결론

기존 8장에 다른 이미지 파일 8장을 추가해 총 16장 × 3버전을 새로 실행했다.
이 표본에서는 기본 `v3.1.3`을 변경할 근거가 확인되지 않았다.
전체 정확도 차이는 **309개 판독 가능 필드 중 단 1개**다. 작은 차이를 일반적인 우열로 해석하지 않는다.

전처리 추가 시간은 기본 대비 v3.2.7 **+8.90ms**, v3.3.1 **+14.46ms**다.
전체 시간에는 외부 OCR 응답 지연이 포함된다. v3.2.7의 전체 시간이 짧았다는 사실을
전처리가 더 빠르다는 뜻으로 해석하면 안 된다.

## 정확도 정의

- 대상: **약 이름, 함량/명시 규격, 1회 투약량, 1일 횟수, 투약 일수**의 5개 필드.
- 원본 시각 전사 후 다른 검토자가 원본과 독립 대조하고, 판독이 엇갈린 부분을 재확인했다.
  전사·검토 과정에서는 OCR 예측 파일을 보지 않았다. 마지막 원본 대조로 불확실한 이름을 제외했다.
- 77개 원본 약 행에서 판독 가능한 309개 필드만 분모로 삼았다.
  원문에 없거나 흐리거나 잘린 값은 `null`로 제외한다. **읽히는데 추출하지 못한 값은 오답**이다.
- 필드별 동일 가중치의 일치율(micro average)이다. 문서 단위 성공률이나 글자 단위 OCR 정확도가 아니다.
- 공백·일부 구분기호·한글/영문 단위 표기, 수치의 `1`/`1.00` 차이는 정규화한다.
  함량의 `0.3g`/`300mg`, `0.1g/1정`/`100mg`도 동등하게 처리한다. 약 이름 오타는 동등 처리하지 않는다.
- 이름의 괄호 성분 설명은 제품명에서 제외하되 `15mL` 같은 명시 규격은 보존한다.
- 원본 행과 결과 행을 대조했다. 표본 16의 v3.2.7은 원본 2·4·5행만 남아 별도 대응표로 채점한다.
  나머지 비어 있지 않은 출력은 원본 행 순서와 개수가 일치한다.

## 실행 조건과 한계

- 기존 8장 manifest를 그대로 보존하고, 최상위 폴더의 미사용 원본 7장 및 하위 폴더 원본 1장을 추가했다.
  생성 이미지·전처리 파생 이미지 폴더는 추가 표본 후보에서 제외했다. 해시가 다른 16개 파일이다.
- **08·11은 같은 문서를 다른 각도로 촬영한 이미지**다. 서로 다른 16개 처방/기관을 뜻하지 않는다.
- 48개 서비스 실행을 직렬로 수행하고 버전 실행 순서를 순환했다. 실제 OCR 42회, LLM 0회.
- 전처리는 별도 직렬 실행으로 각 이미지·버전 3회씩, 총 144회 측정했다.
  표의 전처리 평균은 각 이미지의 3회 중앙값을 낸 다음 16장 평균을 구한 값이다.
- 전체 시간은 서비스 분석 시작부터 완료까지 각 조합 1회 관측값이다.
  프론트엔드 업로드·작업 큐 대기·DB 저장은 제외하며, 운영 LLM 포함 지연이 아니다.
- 외부 OCR 반복 안정성이나 통계적 유의성을 검증한 대규모 평가가 아니다.
  시각 판독·교차검토 기반의 시험용 정답표이며, 의료 전문가가 확정한 정답 데이터셋은 아니다.
  불확실/미표기 필드의 허위 추가 여부까지 포괄하는 정밀도 지표도 아니다.

- 두 실험 스크립트 Ruff 검사/포맷 검사와 수치·함량 정규화 검증 통과.
