# FastAPI 정적 관리자 화면 설계

## 목적

기존 로그인·대시보드 시안을 브라우저에서 직접 실행할 수 있도록 HTML, CSS, JavaScript 파일의 역할을 분리하고 화면 간 이동을 제공한다.

## 구조

```text
app/
└── static/
    ├── index.html                         # 로그인 시작 화면
    ├── css/
    │   └── styles.css                     # 공통·로그인·대시보드 스타일
    ├── js/
    │   ├── login.js                       # 로그인 화면 동작
    │   └── dashboard.js                   # 대시보드 화면 동작
    ├── images/                            # 향후 이미지 자원
    └── templates/
        ├── screen-login.html              # 로그인 화면 시안
        └── screen-dashboard.html          # 대시보드 화면 시안
```

## 화면 동작

- `index.html`을 로그인 시작 화면으로 사용한다.
- 관리자 ID와 비밀번호를 입력할 수 있으며 필수 입력을 검증한다.
- 비밀번호 표시·숨김과 로그인 상태 유지 선택을 제공한다.
- 유효한 입력으로 제출하면 `templates/screen-dashboard.html`로 이동한다.
- 대시보드에서 오늘·7일·30일 기간 선택 상태를 변경할 수 있다.
- 새로고침 버튼은 갱신 시간을 현재 시각으로 바꾼다.
- 로그아웃하면 저장된 로그인 상태를 정리하고 `../index.html`로 돌아간다.
- 현재 범위에서는 실제 FastAPI 인증 API를 호출하지 않는다.

## 연동 기준

- 사용자가 정한 템플릿 위치인 `app/static/templates`를 유지한다.
- 기존 두 HTML 시안의 화면 구성과 콘텐츠를 유지한다.
- Tailwind CDN은 시안 호환을 위해 유지하고 프로젝트 전용 스타일은 `css/styles.css`로 분리한다.
- 각 HTML은 실행 위치에 맞는 상대 경로로 CSS와 JavaScript를 불러온다.
- 향후 FastAPI에서 `app/static`을 `/static`으로 마운트할 수 있지만 이번 범위에는 서버 라우터 변경을 포함하지 않는다.
- 로그인 정보는 실제 인증 전까지 서버로 전송하지 않으며 비밀번호를 저장하지 않는다.

## 검증

- 정적 파일 서버에서 `index.html`과 대시보드가 오류 없이 로드되는지 확인한다.
- 로그인 필수 입력, 비밀번호 표시, 로그인 상태 유지, 화면 이동을 검증한다.
- 대시보드 기간 선택, 새로고침, 로그아웃을 검증한다.
- 기존 Python 테스트를 실행해 백엔드 회귀가 없는지 확인한다.
