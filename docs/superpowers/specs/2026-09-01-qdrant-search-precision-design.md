# Qdrant 검색 정밀도 개선 설계

## 목표

평가 세트를 늘리기 전에 현재 확인된 세 가지 검색 실패를 실제 검색 경로에서 일반 규칙으로 해결한다.

1. 같은 내용을 가진 복수 출처 청크가 함께 반환되는 문제
2. 식별 가능한 약물이 있는데 다른 약물 사례가 섞이는 문제
3. 정확한 질환명보다 의미가 비슷한 다른 질환 문서가 상위에 노출되는 문제

운영 코드에는 특정 질문 문장, 문서 ID, 약물명 또는 질환명을 조건문으로 넣지 않는다.

## 설계

### 공통 결과 정제

Qdrant 검색 저장소가 최종 요청 수보다 많은 후보를 조회한 뒤 모든 소비자에게 동일한 정제 규칙을 적용한다.

- 정규화한 본문, 섹션 유형, 약물·성분 메타데이터로 중복 키를 만든다.
- 중복 키가 같으면 근거 수준, 공개 범위, 문서 ID 순으로 대표 청크를 결정한다. 질문마다 대표 출처가 바뀌지 않도록 유사도는 중복 출처 선택 기준에서 제외한다.
- 질문에 후보 문서의 제목이 정확히 포함되면 같은 제목의 문서를 우선 범위로 사용한다.
- 정확한 제목이 없을 때는 제목·섹션 제목과 질문의 일반화된 어휘 일치도를 유사도와 함께 사용한다.

### 엔터티 필터

약물명, 성분명, 상호작용 쌍 키는 하나 이상의 값이 일치해야 하는 필수 OR 그룹으로 구성한다. 여러 종류의 엔터티가 전달돼도 전체 조건이 선택 사항으로 약화되지 않게 한다.

평가 입력에 식별 가능한 엔터티가 누락된 경우 평가 계약에 구조화 필터를 추가한다. 이는 운영 질문별 하드코딩이 아니라 검색 호출자가 전달해야 할 계약을 보완하는 것이다.

## 합격 기준

- 같은 성분·섹션·내용의 청크는 대표 출처 하나만 남는다.
- 독사조신 질문에서 다른 약물의 이상사례가 반환되지 않는다.
- 과민성대장증후군 정답 문서가 1위이고 하지불안증후군 문서가 Top 5에 없다.
- 기존 14개 평가에서 Hit@5 1.00, 출처 정확도 1.00, 잘못된 대상 혼입 0건을 충족한다.
- 활성 컬렉션은 평가 통과 전까지 v1을 유지한다.

## 비범위

- 질문별 별칭 또는 문서 ID 조건문 추가
- 이번 단계에서 BM25/Sparse 인덱스 신설
- v2 컬렉션의 제자리 수정
- 평가 질문 수 확장
