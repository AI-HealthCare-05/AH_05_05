# 자동 차단 문서 복원·제외 설계

## 목표

`ocr-tesseract-bulk-dry-run-v6`에서 릴리스되지 않은 자동 차단 문서 73건을
신뢰 가능한 소비자용 근거로 자동 복원하거나, 원문 훼손으로 복원이 불가능한
문서는 사람이 다시 확인하지 않아도 되는 제외 상태로 분류한다.

## 분류 정책

| 분류 | 건수 | 처리 |
| --- | ---: | --- |
| 식품안전나라 소비자 리포트 | 32 | `기능성 원료명(인정번호)`를 원료 필드로 인식하고 기능성·일일 섭취량·주의사항을 추출해 릴리스한다. |
| 깨진 `p1-*`, `p2-*` PDF | 35 | 텍스트가 문자 인코딩 손상 상태이고 소비자 리포트 핵심 필드가 없어 `AUTOMATIC_EXCLUDED_UNRECOVERABLE_TEXT`로 제외한다. Qdrant와 수동 검수 대상에 넣지 않는다. |
| 다단·표 구조 연구 논문 | 6 | 본문 읽기 순서 또는 표 행을 결정론적으로 보장할 수 없으므로 수동 검수 문서에만 남긴다. |

## 안전 원칙

- 누락된 원료명·용량·주의사항을 추정해 생성하지 않는다.
- 자동 복원은 원문에 소비자 리포트 필드명이 실제 존재할 때만 수행한다.
- 글자 인코딩이 손상된 문서는 “검색 실패”가 아니라 명시적 제외로 기록한다.
- 읽기 순서 또는 표 구조가 불명확한 연구 논문은 자동 릴리스하지 않는다.

## 데이터 흐름

1. PDF 로더가 텍스트와 레이아웃 경고를 생성한다.
2. 소비자 리포트 파서가 변형된 `기능성 원료명(인정번호)` 필드를 포함해 핵심 네 항목을 추출한다.
3. 품질 판정은 복원·제외·수동 검수 대상을 분리한다.
4. 릴리스에는 복원된 청크만 기록하고, 자동 제외와 수동 검수 목록은 별도 보고서로 기록한다.

## 검증 기준

- 소비자 리포트 변형 헤더가 원료·기능성·일일 섭취량·주의사항 청크를 만든다.
- 인코딩 손상 문서는 릴리스되지 않고 자동 제외 보고서에만 남는다.
- 6개 연구 논문만 수동 검수 Markdown에 포함된다.
- 전체 dry-run에서 분류 합계가 32 자동 복원, 35 자동 제외, 6 수동 검수와 일치한다.
