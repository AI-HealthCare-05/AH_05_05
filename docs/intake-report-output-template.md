# 복용약·영양제 생활관리 보고서 출력 템플릿

> 이 문서는 `POST /api/v1/intake-reports`가 반환하는 `report_markdown`의 최종 출력 형식이다.
>
> 프론트엔드는 같은 응답의 구조화 데이터(`executive_summary`, `current_stack`, `review_cards`, `chart_data`)로 카드·표·그래프를 렌더링한다. 이 Markdown은 읽기·인쇄·PDF 출력용 본문이다.

## 출력 원칙

- 모든 문장은 한국어로 작성한다.
- 등록 정보, 승인된 상호작용 규칙, 공공 자료, 검색된 학술 근거 안에서만 설명한다.
- 근거가 없으면 **"확인하지 못했습니다"** 또는 **"정보가 부족합니다"**라고 명시한다.
- 자료를 찾지 못한 사실을 안전하다는 뜻으로 표현하지 않는다.
- 진단, 처방, 복용 시작·중단·증량·감량을 지시하지 않는다.
- `## 02. 먼저 확인해 주세요`에는 최대 3개 항목만 넣는다.
- 성분별 총섭취량은 제품별 함량과 하루 섭취 횟수가 모두 확인된 경우에만 계산한다.
- 해당 정보가 없는 섹션은 삭제하거나, 필요한 경우 한 줄의 확인 필요 안내만 남긴다.
- 허용 Markdown은 제목(`#`, `##`, `###`), 인용문(`>`), 굵게(`**`), 목록, 표, 링크뿐이다. HTML은 사용하지 않는다.

## 섹션별 출력 규칙

### 01. 한눈에 보는 분석 결과

- 카드형 화면과 동일한 핵심 숫자를 표로 표현한다.
- 전체 요약은 2문장 이내로 작성한다.
- 중복·상호작용이 없더라도 "확인된 항목이 없습니다"라고만 표현하며 안전을 보장하지 않는다.

### 02. 먼저 확인해 주세요

- `review_cards` 중 `priority=CHECK_NOW`를 우선으로, 최대 3개를 표시한다.
- 상호작용, 성분 중복, 정보 부족처럼 사용자가 바로 확인할 수 있는 사실만 적는다.
- "반드시 중단하세요", "복용하지 마세요" 같은 지시 문구는 사용하지 않는다.

### 03. 현재 등록한 약·영양제

- `current_stack`의 각 항목을 한 행으로 출력한다.
- 제품명이나 함량이 불분명한 경우 추정하지 않고 "제품 정보 확인 필요"로 표시한다.

### 04. 성분별 섭취량과 중복 확인

- `calculation_status=COMPLETE`인 성분만 총섭취량 표에 넣는다.
- 함량·횟수 정보가 부족한 제품은 합산하지 않고 07번 섹션으로 보낸다.
- 식단 정보가 등록되지 않은 현재 단계에서는 식단과 영양제의 중복을 판단하지 않는다.

### 05. 상호작용·복용 간격 확인

- 승인된 규칙, 공공 자료 또는 검색된 연구 근거가 있을 때만 구체적으로 설명한다.
- 근거가 없으면 "현재 보유한 자료에서 확인하지 못했습니다"라고 표시하고, 안전하다고 결론 내리지 않는다.
- 약–약, 약–영양제, 영양제–영양제, 약–음식 관계를 동일한 형식으로 표현한다.

### 06. 제품별 역할과 생활관리 안내

- 제품마다 `한 줄 요약 → 등록 정보 → 확인할 점 → 안전한 실천 항목 → 출처` 순서로 작성한다.
- 일반적인 역할은 해당 제품·성분의 확인된 근거가 있을 때만 쓴다.
- 생활관리 문장은 검토된 생활습관 원칙 또는 검색된 근거 안에서만 자연스럽게 정리한다.

### 07. 정보가 부족하거나 근거를 확인하지 못한 항목

- 제품명, 성분명, 함량, 복용 시간, 근거 중 하나라도 부족한 경우를 투명하게 표시한다.
- 사용자가 다음에 등록·확인하면 좋은 정보만 제시한다.

### 08. 오늘의 실천 체크

- 누구에게나 적용 가능한 등록 정보 확인·상담 준비 항목만 제공한다.
- 의학적 판단이나 복용 결정은 포함하지 않는다.

## 근거 표기 용어

| 표시 | 사용 조건 |
| --- | --- |
| 승인된 상호작용 규칙 | 검수 후 활성화된 구조화 상호작용 규칙이 있는 경우 |
| 공공 의약품 자료 | e약은요 등 공공 의약품 정보에서 확인된 경우 |
| 건강기능식품 공공 자료 | 식품의약품안전처 등 공공 건강기능식품 자료에서 확인된 경우 |
| 학술 연구 자료 | Qdrant에서 검색된 관련 연구 근거가 있는 경우 |
| 등록된 복용 정보 | 사용자가 등록한 제품·성분·복용량·시간 정보에 근거한 경우 |
| 확인 필요 | 제품 식별, 함량, 복용 정보 또는 근거가 부족한 경우 |
